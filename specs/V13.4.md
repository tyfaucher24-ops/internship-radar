# V13.4 — Autopilot calendar redesign
Build after V13.3.1. Pull first. Log in CHANGELOG as V13.4. Verify on the LIVE site with screenshots.
Reference mockup (approved by Ty): specs/ref/v13.4-autopilot/ (index.html plus dark.png, light.png, dark-day30.png). Ignore the mockup's nav and fake companies; use the real site nav and the user's REAL tasks.

## Replace the "Due now" tabs with a calendar layout
- Remove the current Due now / status tab UI on Autopilot.
- LEFT: a month calendar (about 600–640px wide) with prev/next month, a Today button, and a Month/Week toggle. Each day shows colored dots per task type: deadline (red), apply-by reminder (purple), follow-up/outreach (blue), interview (green). Today has a green ring; the selected day is highlighted. Days outside the month are dimmed. Filter chips double as the legend.
- RIGHT top: the "Today · Fri, Oct 23 · N tasks" panel (it changes to the selected day). Task cards show logo, role, company, a type dot plus label, time, and buttons: Apply (same purple, same size as Save, opens the job-specific application) and ✓ Mark done. Empty day: a friendly line plus a "Find internships" button.
- RIGHT below: "Upcoming 7 days" list (date, type dot, company · role, type label), clickable to open the listing/task.
- "+ Quick add task" button (title, date, type, optional linked listing). Saved in localStorage like the rest of Autopilot.

## Data
- Tasks come from the real Autopilot data only: saved listings' source-stated deadlines, auto apply-by reminders, follow-ups from Outreach, interviews from the tracker, plus user-added tasks. Never invent deadlines; listings without one don't get a deadline dot.
- Mark done updates the tracker/Outreach where linked. Existing on-site reminders and the .ics export keep working.

## Quality
- Matches the site theme in dark (default) and light, roomy and not crammed, at 1280/1440/1920. Mobile: the calendar stacks above the day panel.
- Keyboard: arrow keys move between days, Enter selects. No layout shift when changing days or months (fixed panel heights with internal scroll).
- Acceptance: screenshots in both themes; select 3 days and verify the right tasks; add, complete and delete a task; confirm a deadline dot appears on the correct date for 5 saved listings.
