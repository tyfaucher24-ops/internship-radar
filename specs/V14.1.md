# V14.1 — Tracker sheet: fully visible, aligned, no crash
Pull first. Log in CHANGELOG as V14.1. Verify on the LIVE site with screenshots in both themes at 1280/1440/1920.
Refs: specs/ref/v14.1-headers-cut.png, v14.1-notes-misaligned.png, v14.1-logo-gap.png

## 1. Nothing cut off
- Column headers are truncated ("FOLLOW-U", "CONTACT/REFE"). Headers must show in full: allow 2-line wrap or use shorter labels (Follow-up, Contact) with a full-name tooltip. Set min-width per column from its header and content.
- Cell text: no silent clipping. Short fields fit; long fields (Role, Notes, Next step) wrap up to 2 lines, and anything longer shows an ellipsis plus the full text on hover and in the edit popover. Role titles like "Intern - Capacity Portfolio Representative Starting Summer 2027" must be readable.
- The page footer hint ("Click any cell to edit… Arrow keys move between c…") is cut off; let it wrap.

## 2. Everything lined up
- Every cell in a row is vertically centered on the same baseline (Notes currently sits lower than Next step). Headers align with their column content (same left padding, same text-align).
- The grade + Realistic pills sit in their OWN column (Grade), not floating under the role.
- Consistent row height (comfortable, about 64px; it grows evenly if text wraps), consistent 16px cell padding.

## 3. Logo-to-company gap
- The big gap between the logo and the company name: put the logo and name in ONE "Company" cell (28–32px logo, 10px gap, then name), with the checkbox column narrow (about 40px).

## 4. Customize sheet "select all" crash (P0)
- Repro: Customize sheet → select every column → the box grows huge, overlaps the page, and the page stops accepting clicks.
- Fix: the Customize panel is a fixed-size popover (max-height about 70vh, internal scroll, Done button always visible); it closes on Done / Esc / outside click; and the backdrop/overlay never stays blocking pointer events.
- With all columns on, the sheet scrolls horizontally inside its container (sticky header row plus sticky Company column), and it never widens the page or breaks layout.
- Add a "Reset to default columns" button. Persist choices in localStorage; if the saved config is corrupted, fall back to default without breaking.
- Find and fix the root cause (console errors, overlay z-index, layout loop) and add a regression test that toggles all columns on/off 5 times and still clicks a row, Save, and the nav.

## 5. Visibility and ease of use
- Bigger readable text (15–16px cells, 13px uppercase headers with letter spacing), strong header contrast, zebra or hover row highlight, and a sticky header while scrolling.
- Light and dark mode both meet AA contrast.

## Acceptance
Screenshots: the default columns and ALL columns on, with long titles and long notes; no clipped headers, all rows aligned, a tight logo–name gap, and no crash; the page stays clickable after customizing. List the test results.
