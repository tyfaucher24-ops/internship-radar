# V10 — UI Cleanup & Functionality Perfection
Ty: "Not very functional yet, I don't even want to stay on the site." Standard: Simple, Functional, Accurate, Fast, Smooth, Visibly pleasing. Log as V10.

## 1. Full audit first
Screenshot every page and state (home, filters, cards, drawer, For You/profile, tracker, alerts, details intro, empty/loading/error states) at 1280/1440/1920 + 390 mobile. List every flaw (spacing, alignment, clipping, inconsistent sizes/fonts/colors, dead or confusing controls, slow interactions). Fix all of them.

## 2. Cleanup rules
- One consistent design system: a type scale (max 4 sizes), spacing scale (4/8px based), one radius, one button style family (small, sleek), one input/dropdown component used everywhere.
- Remove clutter: every element must earn its place. Cut redundant labels, duplicate counts, unneeded badges/tabs.
- Cards: clear hierarchy (logo + company → role → location → deadline → grade). Equal heights, no clipped text, 3-across on desktop.
- Filters: clean, click-to-open searchable panels, active filters as removable chips, instant results.
- Profile: 3 horizontal buckets (Resume, About you, Experience), no long scroll, obvious Save & Search.
- Tracker: roomy spreadsheet feel, inline edit, sort, no horizontal scroll.
- Feedback panel: readable and prominent, not small blue text.

## 3. Functionality
- Every button, link, dropdown, filter, sort, save, and tracker action works on the first try with visible feedback (hover, pressed, saved toast).
- Search/filter results in <150ms; no layout shift; no jank. 60fps scrolling.
- Never lose user data; undo for destructive actions.
- Keyboard navigable, accessible contrast.

## 4. Performance
Lighthouse desktop ≥95, mobile ≥85 (it's currently 68–73, so fix this). Lazy-load logos, virtualize long lists, trim JS.

## 5. Done means
Before/after screenshots for every page, the flaw list with each item marked fixed, QA 123/123 plus new UI checks, zero console errors, Lighthouse scores. Report what's still imperfect. V11 (a visual redesign) follows, so build components that are easy to re-theme (CSS variables/tokens).
