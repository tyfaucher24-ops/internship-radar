# V11.1 design notes: stock-market theme, done quietly

The goal is a market feel that stays calm. It should match the existing Internship Radar look on every page (intro, Find, drawer, tracker, profile), not sit on top of it.

## Patterns borrowed and how they're used

| Source | Pattern | How it is used here |
|---|---|---|
| Robinhood / Public.com | One green and one red, both muted, used only for direction | `--c-up` #0e7c5a and `--c-down` #c2362b in `theme.css`. The ticker, Market tiles, live dots and "closes soon" pills all share these two colours. Grade colours are unchanged. |
| Robinhood | Numbers that roll instead of jumping | Each digit is a 0–9 column moved with `transform` only, eased over 450 ms. Screen readers get the plain number. Reduced motion shows it with no animation. |
| Google Finance / Bloomberg | Ticker as a thin, information-dense strip | The ticker is a 34px hairline strip in the page's surface colour with mono, tabular figures and a time on every item. It is a strip, not a black bar. It pauses on hover and moves slowly (5 s per item). |
| Stripe / Linear dashboards | Hairlines, soft shadows, small uppercase labels above big numbers | Market stat tiles use a tinted background (green-soft / red-soft), a label in small caps and a large tabular number. Card and tile shadows reuse `--shadow-1`. |
| Linear | ⌘K palette | Quick search is a modal with a single field, arrow keys and Enter. It reuses the existing modal styling. |
| Stripe | Motion is subtle and functional | Live dots are 6px with a soft halo every 2.4 s. Only position and opacity animate. All motion stops with reduced motion. |
| Apple / Stripe (dark) | Dark mode reuses the same tokens | Dark mode overrides tokens only, with lighter up/down shades for contrast. The colour-blind mode swaps green for blue in both themes. |

## What was deliberately avoided
- A neon green-on-black "terminal" look, flashing, and red/green fills behind whole rows.
- More than one accent colour per element. Red appears only where something is closing or closed.
- Big moving numbers on every card. Rolling digits appear only on headline counts.
- Fake activity. Every ticker item, count and dot comes from the real sync diff (`data/changes.json`) or the live listings.

## Consistency
- **Intro:** the ticker is a translucent glass strip that matches the counter pill, with the same up/down colours tuned for the dark sky. The counter uses the same mono figures as the Find header.
- **Find:** live dot + mono rolling count in the header, the ticker strip, and a red dot only on cards that close within 7 days.
- **Drawer, tracker, profile:** no new decoration. They pick up the shared tokens, including in dark and colour-blind modes.
