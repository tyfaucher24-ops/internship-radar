# V9 — Accuracy, Polish, Alerts, Honest Grader
Goal: the most accurate internship database, the most honest grader/advisor, and a site where every detail works. Accuracy beats features: never show data we can't verify. Log as V9 in CHANGELOG.md.

## 1. Auto-updating (top priority)
- Data is ~14h stale. The GitHub Actions sync must run automatically at least every 2 hours (tighter for high-churn ATS sources if within limits).
- If blocked by workflow permissions, stop and report exactly what Ty must click/grant (step by step). Do not silently fall back.
- Show "Updated X min ago" in the header from the real last-sync time. If the last sync is >4h old, show a subtle warning and log the failure.
- Each sync: re-verify open status on the company's own posting, remove closed/expired listings (e.g., Michelin closed Sep 30), refresh deadlines, write a sync report (added/removed/changed/failed sources).
- Add a sync-failure alert (e.g., opens a GitHub issue) so failures never go unnoticed.

## 2. Bug fixes (all from the persona report)
1. Searchable dropdowns: rank exact and starts-with matches first, then aliases, then fuzzy. Never auto-pick on partial typing; selection requires click/Enter on a highlighted item. Applies to every dropdown.
2. Sponsorship: "sponsor", "F-1", "OPT", "H-1B", "visa" → "Will need sponsorship." Clear labels for both options.
3. GPA: typing 3.4 selects the bucket containing 3.4. Consider exact numeric input with validation instead of buckets.
4. School list: alias map (Wharton/Penn/UPenn → University of Pennsylvania; MIT; Rutgers; etc.). Exact names beat partial matches (Penn ≠ Penn State).
5. Resume parser: separate name from school, parse degrees correctly ("Associate in Arts" is a degree, not an Art major), correct grad year, recognize major schools (Rutgers, MIT). After parsing, show a "Check these" review step with parsed fields highlighted for the user to confirm.
6. Skills: re-selecting a chosen skill never removes it. Removal only via its × chip.
7. Company names: fix cards showing the job title as the company (e.g., Otis). Validate company field against the registry each sync; flag and fix mismatches.
8. Wrong locations: verify against the source posting; normalize city/state; multi-location shows all.
9. Blank "Got it" button: fix the text/contrast.
10. Reset: confirm dialog stating exactly what is cleared (profile, filters) and what is kept (tracker), with an option to clear the tracker too.

## 3. Polish sweep — "the little things"
- Fix text cut off in text boxes, inputs, dropdowns, chips, cards, buttons, and tooltips everywhere (truncate with ellipsis + full text on hover only where intended; otherwise wrap/grow).
- Audit every page at 1280, 1440, 1920, plus mobile 390: no overflow, no clipping, no horizontal scroll, consistent spacing, alignment, focus states, and empty/loading/error states.
- Keyboard navigation and accessible contrast on all controls.
- Deliver before/after screenshots of every fix.

## 4. Coverage additions
- Big firms: add/fix Citadel, Morgan Stanley, Evercore, Blackstone, Two Sigma, Google, and audit the top ~300 known internship employers (banking, PE, quant, consulting, big tech, F500). Report which are covered and which aren't, and why.
- "Opens around X": for firms not currently hiring, predict the open window only from their real past posting dates. Show as "Expected" with the basis; never present it as fact.
- Visa sponsorship history per company from public data (e.g., DOL H-1B disclosure data). Show the source and year.
- Group near-duplicate listings under one company card ("3 roles at X") instead of repeating.
- Remove "found via GitHub repo" credits from the UI.
- Beginner section: freshman/sophomore programs, first-internship picks, low-competition small companies.

## 5. Grader v2 — fairer, honest, visible
- Slightly less harsh: recalibrate so a solid-fit beginner can see B-range at realistic low-competition roles, while elite roles stay hard (sanity check: no-experience sophomore still under ~60% at JPMorgan/BofA).
- Add role groups (IB, PE, quant, SWE, big tech, consulting, marketing, nursing/health, etc.), firm tiers, and credit for past employers (e.g., a Target employee applying at Target). Re-run all 7 personas: Wharton IB grades must be believable, MIT CS shouldn't get mechanical engineering roles at the top, marketing should get marketing roles before sales, and no single company should take most of the top results.
- Low confidence (thin profile or listing data): show "Not enough info to grade" plus what to add, instead of a misleading score.
- Honest feedback, made prominent: replace the small blue text with a clear feedback panel on each card/drawer:
  - why it's a match (top 2–3 strengths),
  - what's holding you back (honest gaps),
  - what to do to improve your odds (concrete actions: skills, projects, outreach),
  - a plain verdict: "Strong shot / Worth applying / Long shot — here's why."
- Encouraging but truthful tone; a C should read as "worth applying if…", never deceptive.

## 6. Accounts + alerts (opt-in)
- Optional login (email magic link or Google). The site stays fully usable without login; localStorage data migrates on sign-in.
- Alerts, user-controlled: saved-internship deadline reminders (7d/3d/1d), new A/B matches, "firm just opened," status changes. Channels: email and SMS, each with explicit opt-in, frequency (instant/daily/weekly digest), and one-click unsubscribe. SMS requires phone verification and STOP handling.
- GitHub Pages is static: choose a minimal backend (e.g., Supabase for auth/db + Resend for email + Twilio for SMS, or Railway). Propose the stack first and list any keys/accounts Ty must provide. Never store secrets in the repo.

## 7. Accuracy QA (done means)
- Automated checks each sync: closed listings removed, company/title fields valid, locations normalized, no duplicates, deadlines in the future.
- Spot-verify 100 random listings against source postings; report the accuracy %. Target ≥99%.
- Re-run all persona tests and the previous 123 checks; zero console errors; Lighthouse desktop ≥95, mobile ≥85.
- Report: what shipped, screenshots, coverage table, grader before/after per persona, sync status, and anything blocked needing Ty.
