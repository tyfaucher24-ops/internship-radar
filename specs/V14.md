# V14: Build spec (from QA v14 audit)

Build AFTER V13.4. Pull first. Log in CHANGELOG as V14. Full audit with screenshots paths: specs/ref/v14-audit/AUDIT.md (screenshots in /workspace/qa-v14/shots). Never invent data; verify each fix on the LIVE site.

Each item has acceptance tests (AT) that a Playwright script can check. Issue numbers refer to AUDIT.md.

## 1. CSV import (P0, #1)
- Change: in tracker.js, accept the object rows that `parseCSV` returns (map using `Object.keys(rows[0])`), and allow a single data row.
- AT1: Importing a 3-row CSV gives no pageerror, the mapping modal lists the headers, and the tracker gains 3 rows.
- AT2: A CSV with 1 data row imports 1 row.

## 2. Resume experience parser (P0, #2)
- Change: split a "Title, Org  Mon YYYY – Mon YYYY" line into title, org, start and end. Never let a date fragment become the org or title.
- AT1: `sample_resume.pdf` gives title "Investment Banking Summer Analyst", org "Example Capital Partners", start Jun 2026, end Aug 2026.
- AT2: No improve-text on any listing begins with "–" or a month name.

## 3. Data hygiene (P1, #3–5, #16)
- Change, past seasons: drop or close listings whose term is earlier than the current recruiting season (any listing for Summer 2026 or earlier is past).
- Change, dedupe: dedupe on normalized (company, title, location). Keep IDs stable on the source URL, not a hash that changes.
- Change, counts: compute the open count once in meta.json and use it in the header, Find and Profile.
- AT1: 0 open listings have a term of 2026 Summer or earlier.
- AT2: 0 exact company + title + location duplicate groups.
- AT3: The ticker never shows the same company + title as both added and closed on the same day.
- AT4: The header count, the Find count with no filters, and meta.open are equal.
- AT5: If a profile hides listings, Find shows "N hidden by your profile · show all".
- AT6: The Profile "Realistic" number equals the Realistic filter count.

## 4. Grader (P1, #8–12)
- Change: improve-tips come only from the user's selected interests. Fix the grammar templates.
- Change: adding a positive attribute (athlete, leadership, GPA up) never lowers any grade.
- Change: weight interest match and location so that off-interest roles cannot outrank on-interest local roles at the same level.
- Change: with no profile, Match and Realistic sorts are disabled and show "Add profile to use".
- AT1: For a Finance/IB profile, no tip mentions software engineering.
- AT2: Grader check 5 passes, with 0 of 729 grades decreasing.
- AT3: The IB/Boston profile's top 10 includes at least 5 finance roles.
- AT4: Location wording matches between the snapshot and the drawer.
- AT5: The Match % and Realistic sorts produce different orders.
